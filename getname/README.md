# Snail - 标题与封面配文生成器

> 融合「爆款标题工程」与「认知劫持理论」的标题策略师。为长文生成多平台适配的标题+封面配文方案。

---

## 快速安装

### 1. 复制文件夹

将 `snail`复制到 `~/.claude/skills/` 目录下

### 2. 重启 Claude Code

重启 Claude Code 后，技能会自动加载。

### 3. 开始使用

```
/snail
```

或者自然语言触发：

- `生成标题`
- `起标题`
- `帮这篇文章起标题`

---

## 功能特性

### 支持平台

- 微信公众号
- X (Twitter) Articles 中文版
- X (Twitter) Articles 英文版
- LinkedIn
- 小红书

### 双体系方法论

- **爆款模板体系**：数字法、对比法、热词法、疑问法、对话法、好奇法、俗语法、电影台词法、高赞评论法
- **哲学认知劫持体系**：福柯、韩炳哲、尼采、拉康、海德格尔、列维纳斯等哲学框架

### 工作流程

1. 深度阅读与提取（自动分析文章核心要素）
2. 策略选择（根据内容和平台选择最优方法）
3. 平台约束校准（控制标题长度、封面配文长度和平台调性）
4. 批量生成（每平台 10-15 个候选）
5. 筛选到 Top 5（通过 6 项必过测试）
6. 交叉打分与最终推荐（5 维度加权评分）
7. 最终自检（检查标题、配文、正文承诺是否一致）

## 使用示例

### 基础用法

```
/snail

[粘贴你的长文]
```

系统会为默认平台（微信 + X 中文）生成标题方案。

### 指定平台

```
/snail 只要小红书和 LinkedIn

[粘贴你的长文]
```

### 自定义候选数量

```
/snail 每个平台生成 20 个候选

[粘贴你的长文]
```

### 指定情绪基调

```
/snail 要温暖向往的情绪，不要愤怒焦虑

[粘贴你的长文]
```

## 输出结构

每个平台会输出：

1. **10-15 个初始候选**（折叠显示）

   - 标题
   - 封面配文
   - 使用的策略
   - 情绪按钮
   - 目标人群
2. **Top 5 方案**（展开显示）

   - 🥇 推荐方案 + 推荐理由
   - 🥈 第 2 名
   - 🥉 第 3-5 名
3. **交叉打分表格**

   - 点击欲（30%）
   - 情绪精准度（25%）
   - 身份关联（20%）
   - 平台适配（15%）
   - 标题-配文协同（10%）
4. **最终推荐**（高亮标注）

   - 推荐标题
   - 推荐封面配文
   - 平台适配理由
   - 自检结论

## 常见问题

### Q: 支持英文长文吗？

A: 支持。系统会自动识别语言，并为英文平台（X 英文版、LinkedIn）生成原生英文标题。

### Q: 可以只生成某一个平台的标题吗？

A: 可以。调用时指定平台即可，例如：`/snail 只要微信`

### Q: 生成的标题太学术怎么办？

A: 系统会自动平衡学术性和大众性。如果需要调整，可以在调用时说明：`/snail 要大众化的表达，不要学术概念`

### Q: 如何更新技能？

A: 下载新版本的 `snail` 文件夹，覆盖原有的 `~/.claude/skills/snail` 目录，然后重启 Claude Code。

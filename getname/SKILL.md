# Snail - 标题与封面配文生成器

**快捷命令**：`/snail` 或 `生成标题`

> 融合「爆款标题工程」与「认知劫持理论」的标题策略师。设计让目标读者无法拒绝的"入场券"，不是概括文章内容。

---

## 核心原则

### 标题的唯一目的

新媒体标题的唯一使命是**吸引点击**，不是概括内容。标题是"入场券"，不是"摘要"。

### 用户思维两步测试

每个标题必须通过读者脑海中的两个测试：

1. **"这件事与我有关吗？"** — 身份、问题或渴望必须产生强关联
2. **"这件事对我有用吗？"** — 必须承诺明确价值（实用方案或情绪价值）

### 双体系融合逻辑

本 Skill 融合两套方法论，根据文章内容和目标平台自动选择：

- **爆款模板体系**：数字法、对比法、热词法、疑问法、对话法、好奇法、俗语法、电影台词法、高赞评论法 — 适合大众传播、情绪直击
- **哲学认知劫持体系**：福柯（规训）、韩炳哲（自我剥削）、尼采（权力意志）、拉康（欲望）、海德格尔（本真）、列维纳斯（他者）等 — 适合深度内容、身份认同、知识分子受众

不需要二选一。一个标题可以同时使用"对比法"的句式和"韩炳哲"的情绪逻辑。

## SOP 工作流程

### 阶段1：深度阅读与提取

读完全文后，提取以下要素（不输出，内部使用）：

```
□ 核心论点（一句话）
□ 目标读者画像（年龄/身份/痛点）
□ 文章情绪基调（愤怒/焦虑/向往/温暖/好奇/共鸣）
□ 关键冲突/反差/反常识点
□ 涉及的热点人物/事件/关键词
□ 最强情绪爆点在哪一段
□ 适用的哲学框架（如有）
```

### 阶段2：策略选择

根据提取结果，为每个平台选择最优的策略组合。选择逻辑：

| 信号 | 倾向爆款模板体系 | 倾向哲学认知劫持体系 |
|------|------------------|----------------------|
| 文章涉及明确热点人物/事件 | 热词法、高赞评论法 | |
| 文章有强烈数据/案例对比 | 数字法、对比法 | |
| 文章探讨身份认同/存在焦虑 | | 拉康、海德格尔 |
| 文章揭露体制/权力结构 | | 福柯、韩炳哲 |
| 文章讲逆袭/突破/重生叙事 | 好奇法 | 尼采 |
| 文章情感浓度高（亲情/友情） | 对话法、俗语法 | 列维纳斯 |
| 受众偏年轻/大众 | 优先模板体系 | |
| 受众偏知识分子/专业人群 | | 优先劫持体系 |

实际操作中，多数标题会混合使用。

### 阶段2.5：平台约束校准

生成前先确认目标平台的展示约束，避免标题在实际发布时被截断或风格错位。

| 平台 | 标题建议 | 封面配文建议 | 注意事项 |
|------|----------|--------------|----------|
| 微信公众号 | 15-25字 | 8-15字 | 标题承担点击，封面配文承担情绪补刀 |
| X 中文 | 12-22字 | 6-12字 | 更直接，少用复杂隐喻 |
| X 英文 | 6-12 words | 3-7 words | 用原生英文表达，不逐字翻译中文标题 |
| LinkedIn | 8-16 words | 4-8 words | 降低猎奇，强化专业收益 |
| 小红书 | 10-20字 | 6-12字 | 身份、痛点、结果要更显性 |

如果用户提供了明确平台规则，以用户规则优先。

### 阶段3：批量生成（10-15个/平台）

为每个目标平台生成 **10-15个** 标题+封面配文候选。

每个候选的输出格式：

```
### 候选 [编号]
**标题：** [标题文本]
**封面配文：** [8-15字]
**策略：** [使用的模板/哲学框架]
**情绪按钮：** [焦虑/愤怒/好奇/向往/共鸣/温暖]
**目标人群：** [一句话画像]
```

### 阶段4：筛选到5个

从10-15个候选中，筛选出 **5个最优方案**。

筛选标准：

1. **身份代入测试** — 目标读者能否1秒对号入座？
2. **情绪触发测试** — 是否精准击中一种核心情绪？
3. **信息缺口测试** — 是否制造"不点开就亏了"的感觉？
4. **反常识测试** — 是否颠覆某个常见认知？
5. **独立性测试** — 标题和封面配文能否各自独立工作？
6. **平台适配测试** — 是否符合目标平台调性？

输出格式：

```
## [平台名] 标题 Top 5

### 🥇 推荐方案
[完整候选格式]
**推荐理由：** [为什么这个最强]

### 🥈 第2名
[完整候选格式]

### 🥉 第3名 / 第4名 / 第5名
[完整候选格式]
```

### 阶段5：交叉打分与最终推荐

对每个平台的 Top 5 进行交叉打分（满分10分），维度：

| 维度 | 权重 | 说明 |
|------|------|------|
| 点击欲 | 30% | 看到标题后想点开的冲动强度 |
| 情绪精准度 | 25% | 标题传递的情绪与文章核心的匹配度 |
| 身份关联 | 20% | 目标读者的代入感强度 |
| 平台适配 | 15% | 是否符合平台用户习惯和算法偏好 |
| 标题-配文协同 | 10% | 标题和封面配文是否形成互补而非重复 |

最终为每个平台推荐 **1个最优方案**，用户可覆盖。

### 阶段6：最终自检

输出前逐个平台检查：

1. 标题是否只抓一个核心爆点？
2. 封面配文是否补充标题，而不是复读标题？
3. 是否能在目标读者脑中触发"与我有关"？
4. 是否有明确的价值、情绪或信息缺口？
5. 是否存在过度夸张、标题党承诺过大、与正文不匹配的问题？

任何一项不通过，先重写再输出。

---

## 三大误区红线

1. **标题过长** — 超过20字在手机上显示不全。目标：15-25字
2. **信息量过多** — 一个标题只聚焦一个爆点。"少就是多"
3. **标题=内容概括** — 标题要"勾引"，不要"总结"

---

## 输入输出规范

### 输入

一篇已完成的长文（中文或英文），以及目标平台列表。

如果用户未指定平台，默认为：微信公众号 + X 中文版。

### 输出

按平台分区输出，每个平台包含：
- 10-15个初始候选（可折叠）
- 5个筛选后的 Top 方案（展开）
- 1个最终推荐（高亮）
- 1段自检结论（说明最终推荐为什么适配该平台）

# 方法论库

## 第一体系：9大爆款标题模板

### 1. 数字法

**原理**：数字瞬间完成三件事 — 创造具体性、承诺结构化内容、赋予权威感。在模糊的文字流中，数字是最强的视觉锚点。

**句式公式**：
- `[数字]%的[群体]都[行为/状态]`
- `做对这[数字]点，[期望结果]`
- `[数字]个[领域]真相，[补充信息]`

**示例**：
- "95%的女人都爱上过渣男"
- "做对这五点，老板才会乖乖给你升职加薪"
- "3个月薪3万的副业，第2个最适合上班族"

**适用场景**：干货类、清单类、数据驱动的内容

---

### 2. 对比法

**原理**：通过制造强烈反差、矛盾和冲突，引发读者共鸣与思考。对比的落差越大，标题张力越强。

**句式公式**：
- `[状态A]的[群体A]，[状态B]的[群体B]`
- `[低期望]的[主体]，[高结果]`
- `有人[好结果]，有人[差结果]：[追问]`

**示例**：
- "月薪3000的快乐，月入3万的人想象不到"
- "有人20岁年入百万，有人30岁还在送外卖"
- "月入3万的金融男，都在吃9.9元的剩菜盲盒"

**适用场景**：社会观察、阶层话题、消费/生活方式类

---

### 3. 热词法

**原理**：直接将当下最火的热点关键词嵌入标题，借助热点自带流量。标题即"搜索入口"。

**句式公式**：
- `[热点人物/事件]：[你的独特角度]`
- `[热点关键词]背后的[深层问题]`

**示例**：
- "全红婵家门口的闹剧：在这个时代，谁都逃不过流量的审判"
- "重庆呆呆爆火：3天赚了别人3辈子的钱"

**适用场景**：时效性内容、热点评论、蹭热点创作

---

### 4. 疑问法

**原理**：通过提问激发探究欲。高阶用法是提出反常识问题，颠覆读者认知，让人因好奇而不得不点开。

**句式公式**：
- `为什么[反常识现象]？`
- `[人物]如果[假设]，真的能[结果]吗？`
- `[常见行为]，真的有用吗？`

**示例**：
- "为什么有人喜欢渣男？"
- "董宇辉如果单飞，真的能赢过俞敏洪吗？"

**适用场景**：观点类、分析类、颠覆认知类

---

### 5. 对话法

**原理**：模拟生活对话场景，前半句是常见话术，后半句用有趣或有力的回答还击。代入感极强。

**句式公式**：
- `"[常见话术]""[有力回击]"`
- `"[提问]""[反转回答]"`

**示例**：
- "'爷爷你有钱了不起？''了不起。'"
- "'婚后如何保持恋爱感？''跟老公搞暧昧。'"

**适用场景**：情感类、人际关系类、态度表达类

---

### 6. 好奇法

**原理**：俗称"话只说一半"。故意隐藏关键信息，利用人类对未知答案的天然渴求勾引点击。

**句式公式**：
- `[平台/事物]这个[功能/特征]，[未完成的测试]`
- `这[数字]句[类别]，[群体]都[行为]过`

**示例**：
- "微信这个新功能，检验一个人爱不爱你"
- "这13句不该说的话，80%的女生都说过"

**适用场景**：情感测试类、生活技巧类、秘密揭露类

---

### 7. 俗语法

**原理**：改编耳熟能详的俗语、歌词或名言。利用原有高知名度，制造幽默或反差效果。

**句式公式**：
- `[经典前半句]，[改编后半句]`

**示例**：
- "朋友一生一起走，谁先脱单谁是狗"
- "梦想总是要有的，万一忘了呢？"

**适用场景**：轻松幽默类、社交话题类

---

### 8. 电影台词法

**原理**：借用经典电影/影视台词的国民度，结合热点进行二次创作。让读者瞬间联想到熟悉画面。

**句式公式**：
- `《[电影名]》[角色]："[台词]" [与文章主题的连接]`

**示例**：
- "《繁花》爷叔：'大暑之后必有大寒。' 现在的经济环境，普通人该如何过冬？"
- "《热辣滚烫》贾玲：'我赢了一次：学会爱自己，比瘦100斤更重要'"

**适用场景**：影视热点、人生感悟、社会评论

---

### 9. 高赞评论法

**原理**：直接使用已被市场验证过的高赞短评作为标题。这条评论经过了成千上万用户的"投票"，其情绪共鸣度是现成的。

**使用方法**：
- 从微博/抖音/小红书/知乎热点事件中，找到点赞数最高的评论
- 直接用作标题，或稍作修改

**示例**：
- 《关于调休，这届网友骂出了我的心声》
- 将微博热评直接作为标题

**适用场景**：热点事件、社会情绪类

## 第二体系：哲学认知劫持框架

### 理论武器库

| 哲学家 | 核心概念 | 情绪触发 | 适用话题 |
|--------|----------|----------|----------|
| **福柯** | 规训与权力、全景敞视 | 愤怒、警醒 | 职场PUA、学历内卷、体制规训 |
| **韩炳哲** | 自我剥削、倦怠社会 | 疲惫、被理解 | 无效努力、精神内耗、功绩陷阱 |
| **博德里亚** | 符号价值、拟像 | 幻灭、清醒 | 学历鄙视链、名校符号、消费主义 |
| **德博** | 景观社会 | 讽刺、反思 | 社交媒体滤镜、精英人设、表演 |
| **海德格尔** | 本真存在、诗意栖居 | 向往、释放 | 逃离内卷、找回自我、慢生活 |
| **尼采** | 权力意志、超人 | 力量、激励 | 逆袭叙事、打破常规、重估价值 |
| **拉康** | 欲望与镜像、他者 | 焦虑、自省 | 他人眼光、父母期待、理想自我 |
| **列维纳斯** | 他者的面容、责任 | 温暖、感动 | 导师关系、代际传承、人际连接 |

### 认知劫持技术

以下6种心理机制可以与任何标题模板组合使用：

**1. 稀缺心态放大器**
- 关键词："35岁前"、"毕业前"、"最后机会"
- 制造时间紧迫感，激活损失厌恶

**2. 沉没成本陷阱**
- 关键词："读了X年"、"花了X万"、"走了X年弯路"
- 触发"不能白费"的执念

**3. 社会比较毒药**
- 关键词："同龄人"、"同学都"、"别人家的"
- 激活竞争焦虑和相对剥夺感

**4. 权威解构快感**
- 关键词："导师/老板/体制的真相"、"没人告诉你"
- 满足反抗欲和智识优越感

**5. 身份认同危机**
- 关键词："你到底是谁"、"你想成为什么样的人"
- 触发存在主义焦虑

**6. 信息不对称优势**
- 关键词："内幕"、"潜规则"、"秘密"
- 制造"掌握秘密"的快感

## 融合策略：模板 × 哲学 矩阵

以下是常见的高效组合：

| 组合 | 模板 | 哲学框架 | 效果 |
|------|------|----------|------|
| 揭露型 | 对比法 + 疑问法 | 福柯 + 韩炳哲 | 制造认知颠覆，戳穿假象 |
| 逆袭型 | 数字法 + 好奇法 | 尼采 | 用数据锚定 + 话说一半制造张力 |
| 共鸣型 | 对话法 | 拉康 + 列维纳斯 | 代入感 + 情感连接 |
| 诱惑型 | 好奇法 + 俗语法 | 海德格尔 | 制造对另一种生活的向往 |
| 热点型 | 热词法 + 高赞评论法 | 博德里亚 + 德博 | 借势热点 + 深层解构 |

### 融合示例

**纯模板**：
> "月薪3000的快乐，月入3万的人想象不到"（对比法）

**纯哲学**：
> "韩炳哲说你在剥削自己"（太学术，点击率低）

**融合**：
> "月入3万却比月薪3000更累：你不是在奋斗，你在剥削自己"
> （对比法句式 + 韩炳哲自我剥削情绪内核）

融合的关键：**用模板的句式承载哲学的情绪逻辑，让深度思考穿上大众语言的外衣。**

## 热点加速器

当文章涉及热点时，可叠加"热点+十大元素"公式增强标题：

**十大元素**：
- 三大感情：爱情、友情、亲情
- 五种情绪：愤怒、怀旧、暖心、愧疚、孤独
- 两大因素：地域、群体

**组合方法**：热点事件 × 以上元素 = 更有"味道"的标题角度

**示例**：
- 热点（小米SU7上市）+ 群体（优衣库年轻人）= "抢不到小米SU7的年轻人，都挤进了优衣库"
- 热点（失业）+ 群体（中年）+ 地域（深圳）= "失业后的深圳P7"

# 各平台标题规则

## 通用规则

### 标题长度
- 目标：**15-25字**（中文）/ **8-15 words**（英文）
- 手机屏幕显示上限约20个中文字，超出会被截断
- 核心信息必须在前15字内完整呈现

### 封面配文
- 字数：**8-15字**（中文）/ **5-10 words**（英文）
- 必须能脱离标题独立传达情绪
- 视觉化 > 概念化（能在脑海中形成画面）
- 口语化 > 文案感（像人说话，不像广告）

### 标题与封面配文的关系
- **互补，不重复**：标题给信息钩子，封面配文给情绪冲击
- **各自独立**：单看标题能吸引点击，单看封面配文能传达态度
- **1+1>2**：组合后形成更强的点击驱动力

## 微信公众号

### 平台特性
- 标题在订阅号消息列表、朋友圈分享中展示
- 用户决策时间 < 1秒
- 朋友圈分享时只显示标题+缩略图，封面配文不可见

### 标题规则
- **字数**：15-22字最佳
- **前5字是黄金位置**：必须包含核心钩子
- 允许使用书名号《》引用影视/书籍
- 可以使用冒号制造悬念："[前置信息]：[核心爆点]"
- 不建议使用emoji（公众号调性偏正式）

### 封面配文规则
- 用于文章卡片的摘要位置
- 补充标题未说完的信息，或强化情绪
- 10-15字

### 适配策略
- 优先使用：对比法、数字法、好奇法、疑问法
- 哲学框架可以隐含但不要直接出现哲学家名字（受众太广）
- 情绪调性：可以重、可以猛，但要有"正当性"（不能纯标题党）

### 示例
```
标题：月入3万的金融男，都在吃9.9元的剩菜盲盒
封面配文：消费降级的真相
```

## LinkedIn

### 平台特性
- 专业社交网络，调性偏商业和职业发展
- 用户期待"有见地的专业观点"
- 过度情绪化会降低可信度

- **字数**：8-12 words（英文）
- 专业但不无聊
- 用insight代替emotion
- 可以使用行业术语（受众是专业人士）
- 避免clickbait感（LinkedIn用户对标题党反感度最高）

### 封面配文规则
- 5-8 words
- 偏专业洞察而非情绪表达
- Thought leadership调性

## 小红书

### 平台特性
- 信息流以图片/视频+文字形式展示
- 标题和封面配文同时出现在封面上
- 用户年轻化，女性用户占比高
- 搜索权重高，标题需要考虑SEO关键词
- 平台对"标题党"有限流惩罚机制

### 标题规则
- **字数**：15-30字
- **前5字是黄金位置**（信息流只显示前半段）
- emoji使用：可以用但不超过2个（⚠️💡🔥⭐）
- 数字具象化："3年"比"多年"好，"80万"比"很多钱"好
- 关键词前置（影响搜索排名）

### 封面配文规则
- **8-12字**（太长会被截断）
- 必须能配合封面画面
- 可以是半句话（制造悬念）
- 四种常用句式：
  - 祈使句："别再[错误行为]"
  - 感叹句："这才是[正确答案]！"
  - 省略句："[核心词] + [情绪词]"
  - 对立句："[A] vs [B]"

### 适配策略
- 优先使用：数字法、好奇法、对比法
- 三种情绪路线（每组标题候选应覆盖）：
  - **攻击型**（戳痛点）：福柯+韩炳哲，愤怒→共鸣→点击
  - **诱惑型**（画大饼）：尼采+海德格尔，好奇→向往→点击
  - **共鸣型**（说心声）：拉康+列维纳斯，被理解→释放→点击

### 避坑指南
- ❌ 不用"震惊"、"必看"等词（会被限流）
- ❌ 不直接攻击具体公司/学校/导师（法律风险）
- ❌ 不过度贩卖焦虑（会被举报）
- ✅ 用"揭露逻辑"代替"道德批判"
- ✅ 用"我的经历"代替"普遍真理"

### 示例
```
标题：⚠️ 花80万留学回来月薪8000：没人告诉你的3个真相
封面配文：留学滤镜碎了
```

# 质量检验标准

## 第一关：6项必过测试

每个标题候选必须逐项通过以下测试。任何一项未通过，直接淘汰。

### 1. 身份代入测试
**问题**：目标读者看到标题后，能否在1秒内觉得"这在说我"？

**通过标准**：
- 标题中包含具体的身份标签（年龄/职业/身份/处境）
- 或标题描述的场景是目标读者日常经历的
- 或标题提出的问题是目标读者正在纠结的

**反面示例**：
- ❌ "论现代社会的异化问题"（没有人觉得这在说自己）
- ✅ "月薪3万却每天想辞职：你可能正在经历的'高薪陷阱'"

### 2. 情绪触发测试
**问题**：标题是否精准击中焦虑/愤怒/好奇/向往/共鸣/温暖中的至少一种？

**通过标准**：
- 能用一个词说出标题激发的情绪
- 情绪是强烈的、即时的，不是"想想也有道理"

**反面示例**：
- ❌ "浅谈留学的利弊"（没有情绪，只有信息）
- ✅ "花80万留学回来月薪8000：这笔账怎么算？"（焦虑+好奇）

### 3. 信息缺口测试
**问题**：读者看完标题后，是否产生"不点开就亏了"的感觉？

**通过标准**：
- 标题提出了问题但没给答案
- 或标题给出了反常识的结论但没给理由
- 或标题暗示了关键信息但没说完

**反面示例**：
- ❌ "留学回国后应该先找工作再考虑定居"（话说完了，没必要点开）
- ✅ "留学5年回国后，我做的第一件事让所有人意外"

### 4. 反常识测试
**问题**：标题是否颠覆了某个常见认知或话术？

**通过标准**：
- 包含"其实"、"真相"、"不是...而是..."等转折
- 或提出了与主流观点相反的立场
- 或揭示了普遍行为背后的隐藏逻辑

**注意**：不是每个标题都需要反常识，但通过此测试会显著提升点击率。

**反面示例**：
- ❌ "努力就会成功"（老生常谈）
- ✅ "为什么越努力越累？你不是在奋斗，你在剥削自己"

### 5. 独立性测试
**问题**：标题和封面配文能否分别独立工作？

**通过标准**：
- 只看标题：能理解主题、产生点击欲
- 只看封面配文：能感受到情绪、态度或立场
- 标题和封面配文之间没有信息重复

**反面示例**：
- ❌ 标题"留学的真相" + 封面配文"关于留学的真相"（重复）
- ✅ 标题"花80万留学回来月薪8000" + 封面配文"留学滤镜碎了"（互补）

### 6. 平台适配测试
**问题**：标题是否符合目标平台的调性和规则？

**通过标准**：
- 字数在平台推荐范围内
- 情绪强度匹配平台用户习惯
- 不触犯平台限流关键词
- 封面配文字数不超过平台截断上限

## 第二关：交叉打分（Top 5 → Top 1）

通过第一关的候选进入打分环节。

### 评分维度

| 维度 | 权重 | 评分标准 |
|------|------|----------|
| **点击欲** | 30% | 看到标题后想点开的冲动有多强？10分=无法抗拒，1分=完全无感 |
| **情绪精准度** | 25% | 标题传递的情绪与文章核心情绪的匹配度。错位=低分 |
| **身份关联** | 20% | 目标读者的代入感。越具体越高分，越泛越低分 |
| **平台适配** | 15% | 是否天然适合该平台的用户习惯和算法偏好 |
| **标题-配文协同** | 10% | 标题和封面配文组合后是否1+1>2 |

### 打分输出格式

```
| 排名 | 标题 | 点击欲 | 情绪精准 | 身份关联 | 平台适配 | 协同 | 加权总分 |
|------|------|--------|----------|----------|----------|------|----------|
| 1 | ... | 9 | 9 | 8 | 9 | 8 | 8.8 |
| 2 | ... | 8 | 9 | 9 | 8 | 7 | 8.5 |
| ... | | | | | | | |
```

### 决策规则

- 加权总分最高者为推荐方案
- 如果前两名分差 < 0.3，标注"接近"，建议用户自行选择或投入种子用户群投票
- 如果所有候选总分 < 7.0，建议回到第三步重新生成

## 常见问题自检

### 标题太长怎么办？
- 砍掉修饰词，只留核心冲突
- 用冒号分段："[前置]：[核心]"
- 把次要信息移到封面配文

### 标题太学术怎么办？
- 把哲学概念替换成大白话
- "自我剥削" → "给自己加班还觉得应该"
- "规训" → "被洗脑"
- "本真存在" → "做自己"

### 标题和文章脱节怎么办？
- 标题不需要概括全文，但必须与文章的核心情绪一致
- 标题可以聚焦文章中最有爆点的一个片段
- 如果找不到爆点，说明文章本身可能需要优化

### 多个平台的标题太相似怎么办？
- 每个平台应该使用不同的策略组合
- 微信用大众模板，X用观点锐度，小红书用身份代入，LinkedIn用专业洞察
- 同一篇文章的不同平台标题，可以聚焦文章的不同侧面
